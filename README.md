# repo-size

A Chrome extension that display the repo size

## How to Install Manually

1. Download or clone this repo
2. Go to `chrome://extensions`
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select the folder

## Why?
because some people want to know a repository's size before cloning it. I'm a bit of a storage miser myself, so I want to know how much disk space a repository is going to take up before I clone it. 😅

No one wants to clone a huge repository only to find out it eats up more storage than expected!
